八阶段学习路径

按顺序走，别跳级——每一阶段都是下一阶段的地基

  1. 1

    计算机与网络基础

    第 1–2 周 · 入门 地基

    目标：能说清「一个 HTTP 请求从浏览器到数据库经历了什么」，能自己装一台虚拟机并配好网络。

    核心知识

    CPU / 内存 / 磁盘 / IO 的关系 进程与线程、上下文切换 TCP/IP 四层模型 三次握手与四次挥手 DNS 解析流程 HTTP 状态码语义 子网掩码与路由

    动手练习

    装 CentOS/Ubuntu 虚拟机 用 ping / traceroute / curl 验证网络 tcpdump 抓一次 HTTP 请求 用 dig 观察 DNS 递归过程

    自检标准

    能画出请求全链路图 能解释 502 和 504 的区别
  2. 2

    Linux 系统管理

    第 3–6 周 · 入门 → 初级 吃饭本领

    目标：不靠图形界面完成日常全部操作；能在无外网的机器上装好一套运行环境。

    核心知识

    文件系统与目录规范（FHS） 权限、umask、ACL、sudo 用户与用户组管理 软件包管理 yum/apt systemd 服务管理 日志体系 journald / rsyslog 磁盘分区与 LVM 定时任务 cron

    动手练习

    写 5 个以上实用 Shell 脚本 用 LVM 在线扩容一次 配一个 systemd 自启服务 logrotate 切割日志

    自检标准

    能徒手定位磁盘是谁占满的 能说清 inode 是什么
  3. 3

    Shell 与自动化脚本

    第 5–8 周 · 初级 效率分水岭

    目标：把重复操作变成脚本；从「手动运维」跨到「工具运维」。

    核心知识

    变量、数组、条件、循环 函数与模块化 管道与文本三剑客 grep/sed/awk 退出码与错误处理 set -euo pipefail Python 基础（运维视角） paramiko / requests 调用

    动手练习

    批量巡检脚本（CPU/磁盘/证书） 日志分析 awk 脚本 Python 批量 SSH 执行命令 脚本结果推送到钉钉/企微

    自检标准

    脚本能在异常时不误删数据 一条 awk 能出统计报表
  4. 4

    服务部署与中间件

    第 7–12 周 · 初级 → 中级 实施核心

    目标：独立部署一套「Nginx + 应用 + MySQL + Redis」的完整业务系统，并完成参数调优。

    核心知识

    Nginx 反向代理 / 负载均衡 / 限流 Tomcat 与 JVM 基础参数 MySQL 安装、备份恢复、主从复制 Redis 部署、持久化、哨兵 消息队列 Kafka / RabbitMQ HTTPS 证书配置与续期

    动手练习

    搭一套主从 + 读写分离 配置 Nginx 灰度与限流 做一次 binlog 时间点恢复 压测一台 Nginx 找瓶颈

    自检标准

    能解释主从延迟的成因 能背出 Nginx 502 排查顺序
  5. 5

    监控、日志与可观测性

    第 11–16 周 · 中级 从救火到防火

    目标：系统出问题前你就知道；出问题后 5 分钟内能定位到是哪个环节。

    核心知识

    Prometheus + Exporter + PromQL Grafana 看板设计 Alertmanager 告警分级与降噪 Zabbix 传统监控 ELK / Loki 日志平台 四种黄金指标与 SLO 链路追踪与 traceId

    动手练习

    部署 node_exporter + Grafana 大盘 写 10 条有用的告警规则 搭一套 Filebeat→ES→Kibana 做一次告警风暴演练

    自检标准

    能从大盘 3 步定位到根因 告警零噪音、都有 runbook
  6. 6

    容器与云原生

    第 15–20 周 · 中级 当下主流

    目标：把一套传统部署的应用容器化并跑在 K8s 上，能独立排查 Pod 异常。

    核心知识

    镜像分层与 Dockerfile 优化 容器网络与存储卷 K8s 核心对象（Pod/Deploy/Svc/Ingress） 探针、资源配额与 QoS Helm 与配置管理 K8s 排障四板斧

    动手练习

    写多阶段构建 Dockerfile kubeadm 搭三节点集群 迁移一个无状态服务上 K8s 模拟 Pending / CrashLoop 排查

    自检标准

    能讲清 requests/limits 的后果 能说出 Pod 起不来的 6 种原因
  7. 7

    云平台、自动化与 CI/CD

    第 19–24 周 · 中级 → 高级 规模化能力

    目标：一人管理上百台机器；一次提交自动构建、发布、回滚。

    核心知识

    云上 VPC / 安全组 / SLB / 对象存储 Ansible 批量配置管理 Jenkins / GitLab CI Pipeline 制品与镜像仓库 灰度发布与回滚策略 IaC（Terraform）与配置分离

    动手练习

    Ansible 一键初始化 50 台机器 搭 Jenkins 自动发布到测试环境 用 Terraform 创建一套 VPC 做一次蓝绿发布演练

    自检标准

    发布全流程无人值守 回滚时间 < 5 分钟
  8. 8

    安全合规、实施交付与稳定性体系

    第 23 周起 · 高级 → 专家 体系与影响力

    目标：能主导一个项目的交付与运维体系设计，对客户/领导讲清方案与风险。

    核心知识

    主机加固与基线 等保 2.0 三级要求 应急响应与取证 实施方法论（调研→部署→验收） 容量规划与成本优化 故障复盘与 SRE 体系

    动手练习

    写一份主机加固基线文档 做一次渗透后的应急演练 输出一份完整实施方案 写一份真实故障复盘

    自检标准

    能独立应对客户现场突发 能讲清一套运维体系的建设顺序

24 周执行计划

每周 8–10 小时，边学边做，产出可写进简历

第 1–6 周 · 打地基

  • 第 1–2 周：操作系统 + 网络基础，画一张请求全链路图
  • 第 3–4 周：Linux 命令与权限，装好实验环境（VM + 快照）
  • 第 5–6 周：Shell 脚本，产出 3 个可复用脚本

产出物：一份《Linux 常用命令速查 + 5 个运维脚本》

第 7–12 周 · 会部署

  • 第 7–9 周：Nginx + 应用 + MySQL 完整部署
  • 第 10–11 周：Redis、主从复制、备份恢复
  • 第 12 周：HTTPS、限流、压测与调优

产出物：一套可重复部署的《标准业务系统部署手册》

第 13–18 周 · 能看见

  • 第 13–15 周：Prometheus + Grafana + 告警
  • 第 16–17 周：ELK 日志平台
  • 第 18 周：一次完整的故障演练与复盘

产出物：《监控大盘 + 告警规则集 + 排障 runbook》

第 19–24 周 · 上规模

  • 第 19–21 周：Docker + K8s 部署与排障
  • 第 22–23 周：Ansible + CI/CD 流水线
  • 第 24 周：安全加固与等保要求梳理

产出物：《容器化迁移案例 + 自动化发布流水线》
